# TheoTown Dragon Mod 🐉

**A majestic plugin that adds dragons to TheoTown!**

Created by the kind dragon with a saddle (and his rider).

## Features (planned)
- Dragon-themed buildings and decorations
- Flying dragon animations / scripts
- Dragon parks and monuments
- Special dragon residential / commercial zones
- Fire effects and smoke

## Installation
1. Download / clone this repository
2. Place the folder into your TheoTown plugins directory
3. Restart the game or reload plugins

## Structure
```
theotown-dragon-mod/
├── plugin.manifest
├── dragons.json
├── (images .png)
└── README.md
```
